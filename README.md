# Engulfing Lightning 更新内容

## v1.3

### 机制修改

1. 缩小了伤害的判定，由范围伤害变成单体伤害。

2. 生成的雷电实体本身不再造成伤害，而是视为**玩家攻击的伤害**。

### 数值修改：

- 攻击距离=30+15*击退等级

- 最大雷电数量=10+10*横扫之刃等级

- 雷电伤害=
max(
  (5+锋利等级)*2,
  当锋利等级为n时，有min(20n%, 100%)的概率为生物血量上限/3，否则为生物血量上限/6
)

- 扣除耐久=雷电数量/(耐久等级+1)（每次扣除耐久时，会触发原版耐久附魔的概率减免）

### 说明
​
​- 伤害判定变为单体，但雷电的作用范围不变，也就是说范围内的苦力怕不受伤而会被激活。

- 怪物死亡的时候，会正常生成经验和掉落物（抢夺生效）。

- 由于雷伤视为**玩家攻击的伤害**，免疫雷伤的生物也会受到伤害。
