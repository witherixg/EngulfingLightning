# Engulfing Lightning 更新内容

## v1.9

- 修复了部分情况下**薙草之稻光**攻击实体崩溃的问题。
- 修复了**薙草之稻光**召唤的雷电的伤害结算异常的问题。
- 修复了部分情况下可能导致内存溢出的问题。

## v1.8

- 修复了**薙草之稻光**召唤的雷电的死亡文本。
- 修复了**薙草之稻光**攻击生物不造成伤害时不生成雷电的问题。
- 新增**摧毁**附魔：

  - 不可通过附魔台、村民交易、钓鱼获取。
  - 当**薙草之稻光**受到爆炸伤害时，为它施加该附魔。
  - 当持有带**摧毁**附魔的**薙草之稻光**的玩家通过**使用键**召唤雷电杀死实体时，不会生成掉落物。

## v1.7

- 对基础伤害的修改：基础伤害 $\ =(5\ +$ 锋利等级 $)*2$
- 当手持**薙草之稻光**对生物按下使用键时，不再会在该生物的位置召唤雷电。
- 当手持**薙草之稻光**按下使用键时，冷却时间变为 $10$ 秒。
- 当手持**薙草之稻光**攻击生物时，如果满足下列条件之一，则在生物的位置召唤雷电：
  
  - 当生物被**薙草之稻光**攻击时，此次攻击的前两次攻击(如果存在)均未召唤雷电。
  - **薙草之稻光**对该生物的上次召唤雷电的时间和此次攻击时间相隔大于 $2.5$ 秒。

- 为**薙草之稻光**召唤的雷电伤害添加死亡文本。

## v1.6

- 当**薙草之稻光**带有**磁化**附魔时，传送的掉落物不再有**拾取冷却**。
- **薙草之稻光**召唤的雷电将无视**一切伤害减免**。

## v1.5

- 重构了部分代码。
- 将**雷霆的威光**和**稻光神鸣**添加到创造物品栏的**工具与实用物品**部分。

- 对暴击伤害的修改：

  - 暴击率 $=$ 锋利等级 $/\ 8$。
  - 暴击时，伤害 $=$ 最大生命值 $/\ 10$。
  - 否则伤害 $=$ 最大生命值 $/\ 20$。

## v1.4

### 新增内容：磁化附魔

- 不可通过附魔台、村民交易、钓鱼获取。
- 当**薙草之稻光**在磁石上被雷电击中时，为它施加该附魔。
- 当持有带**磁化**附魔的**薙草之稻光**的玩家通过召唤雷电杀死实体时，会将掉落物和经验球传送到玩家的位置。

### 数值改动

- 对暴击伤害的修改：

  - 暴击率 $=$ 锋利等级 $/\ 5$。
  - 暴击时，伤害 $=$ 最大生命值 $/\ 3$。
  - 否则伤害 $=$ 最大生命值 $/\ 6$。

- 扣除耐久时，不再与原版耐久附魔的概率减免产生叠加效果。

## v1.3

### 机制修改

- 缩小了伤害的判定，由范围伤害变成单体伤害。

- 生成的雷电实体本身不再造成伤害，而是视为**玩家攻击的伤害**。

### 数值修改

- 攻击距离 $=30+15 \times$ 击退等级。

- 最大雷电数量 $=10+10 \times$ 横扫之刃等级。

- 雷电伤害
  $=\max(
  (5+$ 锋利等级 $)*2,$ 
  暴击伤害
  $)$。
  - 暴击率 $=$ 锋利等级 $/\ 5$。
  - 暴击时，伤害 $=$ 最大生命值 $/\ 3$。
  - 否则伤害 $=$ 最大生命值 $/\ 6$。

- 扣除耐久=雷电数量 $/($ 耐久等级 $+1)$(每次扣除耐久时，会触发原版耐久附魔的概率减免)。

### 说明

- 伤害判定变为单体，但雷电的作用范围不变，也就是说范围内的苦力怕不受伤而会被激活。

- 怪物死亡的时候，会正常生成经验和掉落物(抢夺生效)。

- 由于雷伤视为**玩家攻击的伤害**，免疫雷伤的生物也会受到伤害。

## v1.2

### 声明

v1.2之前的版本更新内容为后续补充。

### 数值修改

- 现在，薙草之稻光在召唤雷电时，如果目标实体的生命值较高，则产生**暴击**效果：

  雷电伤害
  $=\max(
  5+$ 锋利等级 $,$
  暴击伤害
  $)$
  - 暴击率 $=$ 锋利等级 $/\ 5$
  - 暴击时，伤害 $=$ 最大生命值 $/\ 3$
  - 否则伤害 $=$ 最大生命值 $/\ 6$

- **薙草之稻光**召唤的雷电既不会生成火焰，也不会为实体附着火焰，并且最多在世界上存在 $1$ 游戏刻。
